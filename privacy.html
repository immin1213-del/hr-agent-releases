코니 개인정보처리방침

시행일: 2026년 10월 22일

코니(Koni, 이하 "앱")는 사용자 PC에서 실행되는 Windows용 데스크톱 앱입니다. 이 방침은 앱이 어떤 정보에 접근하고 어떻게 다루는지 설명합니다.

1. 접근하는 구글 사용자 데이터

사용자가 앱에서 "구글 연결"을 직접 승인한 경우에만 다음 권한을 사용합니다.

  • 캘린더 읽기 (calendar.readonly): 오늘·이번 주 일정을 읽어 아침 브리핑과 회의 알림을 보여 줍니다.
  • 캘린더 일정 추가 (calendar.events): 사용자가 요청하고 확인 버튼을 누른 일정만 기본 캘린더에 추가합니다. 기존 일정을 수정하거나 삭제하지 않습니다.
  • 할 일 읽기 (tasks.readonly): 아침 브리핑에 마감이 가까운 할 일을 보여 줍니다.

2. 데이터 저장과 전송

  • 구글 로그인 토큰은 Windows 암호화 기능으로 암호화해 사용자 PC에만 저장합니다.
  • 캘린더·할 일 내용은 화면 표시를 위해 메모리에서만 사용하며, 운영자 서버나 제3자에게 보내지 않습니다. 앱에는 운영자 서버가 없습니다.
  • 질문 기록, 메모, 설정은 사용자 PC에만 저장됩니다.

3. AI 처리

  • 기본값인 로컬 AI(Ollama)를 사용하면 모든 처리가 사용자 PC 안에서 이루어집니다.
  • 사용자가 설정에서 클라우드 AI(Anthropic Claude 또는 Google Gemini)를 직접 고르고 동의한 경우에만, 사용자가 입력한 질문과 앱이 찾은 규정·법령 문구, 일정 추가 요청 문장이 해당 AI 서비스로 전송됩니다. 이때는 사용자 본인의 API 키를 사용하며, 각 서비스의 개인정보 정책이 적용됩니다.
  • 구글 캘린더나 Tasks에서 가져온 데이터는 AI 서비스로 보내지 않으며, AI 모델 학습에 사용하지 않습니다.

4. 구글 API 서비스 사용자 데이터 정책 준수

앱이 구글 API에서 받은 정보를 사용하고 다른 앱으로 전송하는 방식은 제한적 사용(Limited Use) 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.

5. 데이터 삭제

  • 구글 계정 권한 페이지에서 언제든 앱 권한을 철회할 수 있습니다.
  • 앱을 지우고 %APPDATA%\코니 폴더를 삭제하면 PC에 저장된 모든 데이터가 지워집니다.
